# Datathon — Fase 05

Este diretório reúne materiais públicos de apoio ao Datathon da Fase 05. Cada subpasta corresponde a um pacote curado para uma turma ou ciclo específico, mantendo o foco em orientação didática, problema de negócio e regras de entrega.

## Pacotes disponíveis

| Pacote | Uso recomendado |
| --- | --- |
| [6mlet](6mlet/) | Guia amplo de desenvolvimento do desafio, com maturidade MLOps e checklist de entrega. |
| [7mlet](7mlet/) | Caso de negócio financeiro para o Datathon 7-MLET: experimentação adaptativa em ofertas. |

## Regra de publicação

Materiais deste diretório devem enquadrar o problema, os limites de dados, os entregáveis e os critérios de avaliação. Eles não devem publicar solução pronta, arquitetura obrigatória, prompts reutilizáveis como resposta final, dados privados ou atalhos de avaliação.
